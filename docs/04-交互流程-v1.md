# 交互流程 v1 — 用户视角说明书

> 说明：描述当前 MVP **已实现**的交互。所有数据均为模型真实输出。
> 版本：2026-08-06

---

## 一、总览

```
[输入问题] → [拆Token] → [逐步生成(自动)] → [完整答案] → [可再问]
     ↑                                            │
     └────────── 下一轮（历史折叠）←──────────────┘
```

**一句话**：你提问 → 看模型把问题拆开 → 看它一个字一个字"抽"出回答 → 读完整答案 → 继续问。

---

## 二、分阶段流程

### 阶段 0：等待输入（IDLE）

| 项 | 内容 |
|---|---|
| 界面 | 顶部标题栏 + 中间聊天区 + 底部输入框 |
| 用户可做 | 在输入框打字、点"生成" |
| 限制 | 最多 100 个中文字符（超了会弹错误提示） |
| 下一步 | 提交问题 → 进入阶段 1 |

### 阶段 1：提交与校验（SUBMITTING）

| 项 | 内容 |
|---|---|
| 发生什么 | 输入框清空、按钮禁用，防止重复提交 |
| 校验 | 前端+后端双重校验长度；空输入 / 超长 → 显示错误，回到阶段 0 |
| 用户可做 | 只能等待（约 1 秒） |
| 下一步 | 校验通过 → 进入阶段 2 |

### 阶段 2：拆 Token（TOKENIZING）

| 项 | 内容 |
|---|---|
| 发生什么 | 出现「生成过程」面板；你的问题被拆成一个个 Token 卡片，卡片下方标真实 ID |
| 同时显示 | 解释条（为什么拆 Token、开头特殊符号是系统设定）；若有历史轮次，显示灰色折叠块「前 N 轮已参与计算」 |
| 用户可做 | 悬停 Token 卡片看 ID；悬停虚线词看术语解释 |
| 下一步 | 自动进入阶段 3（无需操作） |

### 阶段 3：逐字生成（GENERATING）— 核心环节

**当前为自动播放**，每生成一个字重复以下循环（每步约 0.2 秒）：

```
第 N 步：
  ① 5 张候选卡出现（模型觉得最可能的"下一个词"）
  ② 每张卡概率条从 0 涨到真实概率值（百分比）
  ③ 其中一张被选中：高亮变蓝 + 边框发光
  ④ 选中词块追加到下方"回答序列"区
  ⑤ 进入第 N+1 步
```

| 项 | 内容 |
|---|---|
| 用户可做 | 只能观看；悬停候选卡看 token ID |
| 特殊情况 | 若选中非第一名 / 概率很低 → 该步顶部弹黄色「注意」条（教学时刻，每轮最多 3 次） |
| 结束条件 | 模型输出结束符，或达到 200 token 上限 |

### 阶段 4：完成（ANSWER_READY）

| 项 | 内容 |
|---|---|
| 发生什么 | 面板顶部显示"完成 · N 步"；出现「机制解释」条（这些 Token 拼成了完整回答）；完整答案以消息形式出现在聊天区 |
| 同时显示 | 底部小字：总步数、耗时、停止原因 |
| 用户可做 | 阅读答案；输入框恢复可用 |
| 下一步 | 输入下一个问题 → 回到阶段 1 |

### 阶段 5：多轮与历史（每轮新开始时）

| 项 | 内容 |
|---|---|
| 发生什么 | 之前所有轮次的过程面板**折叠**成一行灰条「历史上下文 · 前 N 轮」；上一轮答案保留在聊天区 |
| 原因 | 历史确实作为 Token 参与了本轮计算，但界面折叠展示（后端只保留最近 3 轮） |
| 用户可做 | 继续提问，不受影响 |

### 阶段 6：出错（ERROR）

| 项 | 内容 |
|---|---|
| 触发 | 输入为空 / 超长 / 后端连接断开 |
| 界面 | 聊天区出现红色错误框 + 顶部状态变"出错" |
| 恢复 | 输入框恢复可用，重新提交即可 |

## 三、用户能做什么 / 不能做什么

| ✅ 能 | ❌ 不能 |
|---|---|
| 输入问题、提交 | 暂停/回退生成过程 |
| 观看每一字生成 | 选择或修改候选 Token |
| 悬停查看 Token ID、术语解释 | 调整温度等生成参数 |
| 连续多轮提问 | 干预生成路径 |
| （待改）手动控制展示节奏 | — |

---

## 四、顶部状态徽标

```
就绪(IDLE) → 提交中 → TOKENIZING → 生成中·步骤N → 完成 → 就绪
                  ↘ 出错(可恢复)
```
